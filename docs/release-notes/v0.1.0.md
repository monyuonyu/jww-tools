First release of `jww2dxf`, a converter from [Jw_cad](https://www.jwcad.net/) drawings (`.jww`) and registered symbols (`.jws`) to DXF. It reads every data version found in the wild (220–700, i.e. Jw_cad for Windows 2.x up to the current 10.x) and was checked figure by figure against Jw_cad's own DXF export on 307 drawings: all 152,625 lines, 10,001 arcs/circles/ellipses, 2,313 points, 22,116 texts, 1,085 solids and 16 images match. See the [README](https://github.com/monyuonyu/jww-tools#readme) ([日本語](https://github.com/monyuonyu/jww-tools/blob/main/README.ja.md), [简体中文](https://github.com/monyuonyu/jww-tools/blob/main/README.zh-CN.md)).

**What it converts**
- lines, circles, arcs, tilted/flattened ellipses, points (also temporary points), texts (fonts, italic, vertical, `・` padding as Fit text), dimensions, solids (quadrilaterals and arc/ring solids, RGB colours), blocks (nested, scaled, rotated, mirrored), linked and embedded images (`IMAGE`, embedded files extracted)
- layer groups × layers with their names and hidden state, line types, pen colours, line widths
- DXF R2000 (Shift_JIS, default), R2007 (UTF-8, `--utf8`) or R12; `--json` dumps everything that was read
- coordinates like Jw_cad's own export (sheet lower-left at 0,0, scale of the current layer group); `--center`, `--group-scale`, `--paper` for other choices

Used by [freecad-ja-unified](https://github.com/monyuonyu/freecad-ja-unified) to open `.jww` files.
