`jww2dxf` can now tell you about outlines that are split into pieces or drawn twice — common in Jw_cad drawings and a nuisance when the converted drawing is edited. Without the new options the DXF is the same as with 0.1.0, byte for byte (checked on 1,168 distinct drawings with four output settings; the comparison with Jw_cad's own export still matches on all 307 drawings). See the [README](https://github.com/monyuonyu/jww-tools#duplicate-and-overlapping-lines) ([日本語](https://github.com/monyuonyu/jww-tools/blob/main/README.ja.md#二重の線重なった線), [简体中文](https://github.com/monyuonyu/jww-tools/blob/main/README.zh-CN.md#重复和重叠的直线)).

**New**
- `--check` (or `--warn-overlaps`): lists duplicate lines (either direction), overlapping collinear lines, duplicate circles/ellipses/arcs, and — as information — collinear lines that touch end to end, on one layer and across layers, with figure numbers, DXF layer names and DXF coordinates. The exit status stays 0 unless `--strict` is given (then 4).
- `--json` has a `check` object and an `issues` array with every finding.
- `--merge-collinear`: writes each run of collinear lines that overlap or touch (same layer, line type, colour and width) as one line. Off by default.
- `--tol MM`: the tolerance, in DXF millimetres (default one millionth of the drawing's size, at least 0.0001 mm). A grid index keeps it fast: 165,000 lines in under a second.
